# ตารางจับคู่เฟส — แผนหลัก ↔ แผนดำเนินงาน

อ้างอิง:  
- แผนหลัก: `docs/00-แผนหลักระยะที่-1.md` (Phase 1–5)  
- แผนดำเนินงาน: `docs/10-แผนดำเนินงานระยะที่-1.md` (เฟส 0–6 + Gate)  

งาน: DCS-P0-001 | วันที่: 2569-07-16

## หลักการ

- **แผนหลัก** กำหนดขอบเขตส่งมอบและลำดับความสามารถระบบ  
- **แผนดำเนินงาน** กำหนด Gate, Pilot, DoD และการพิสูจน์  
- เมื่อชื่อเฟสไม่ตรงกัน ใช้ตารางนี้เป็นสะพาน — **ห้ามใช้เฟสหนึ่งตัดขอบเขตของอีกเอกสาร**

## ตารางจับคู่

| แผนดำเนินงาน (`docs/10`) | แผนหลัก (`docs/00`) | เนื้อหาหลัก | หมายเหตุ |
|--------------------------|---------------------|-------------|---------|
| **เฟส 0** จัดเอกสาร ADR/Contract/Spec | *(ก่อน Phase 1 อย่างเป็นทางการ)* | ADR, Dictionary, Spec | = งาน **DCS-P0-001**; แผนหลักระบุสร้าง ADR/Dictionary ภายในรายการ Phase 1 ข้อ 7/10 — **แยกทำก่อน scaffold ได้** |
| **เฟส 1** Scaffold จำลอง | **Phase 1** (โครงสร้าง+เครื่องมือ จำลอง) | git, โครง apps-script, lint/typecheck/unit mock, TS build | ห้าม clasp push / Workspace |
| **เฟส 2** สิทธิ์ Audit Contract ในโค้ด | **Phase 2** Backend Core (ส่วนต้น) | RBAC, Audit, Repository | ต่อ Sheet จริงเมื่อ Gate S |
| **เฟส 3** Pilot หนังสือภายใน | **Phase 3** Business Logic (แนวตั้งแรก) + ส่วน **Phase 4** ที่จำเป็นต่อ slice | workflow เต็ม + ยกเลิก/แทนที่ domain | Pilot ≠ ตัด 5 ชนิด |
| **เฟส 4** ครบ 6 ชนิดหนังสือ | **Phase 3** ขยายชนิด + **Phase 4** UI ตามชนิด | แม่แบบ 6 ชนิด | ขอบเขตส่งมอบระยะที่ 1 |
| **เฟส 5** รายงาน Backup ปฏิบัติการ | **Phase 2–4** ส่วนรายงาน/backup job + docs/04 | Restore Test | ก่อน Gate P |
| **เฟส 6** พิสูจน์ขีดความสามารถ + เตรียม Prod | **Phase 5** Testing & Release | Load/Concurrency/Soak, Human Approval | ห้ามเคลม 2,000+ โดยไม่มีผลทดสอบ |

## Gates (แผนดำเนินงาน) กับเงื่อนไขแผนหลัก

| Gate | ความหมาย | ผูกกับแผนหลัก |
|------|----------|----------------|
| Gate 0 | ADR/ข้อเสนอชั่วคราวบันทึกแล้ว → งานจำลองได้ | ADR ใน `docs/adr/` + เงื่อนไข Phase 1 จำลอง |
| Gate S | ได้สิทธิ์ Workspace/Staging | ปลดล็อก “ต่อ Google Sheets เมื่อมีสิทธิ์” ใน Phase 2 |
| Gate 1 | ก่อน UAT จริง | D-03/D-04 และข้อปฏิบัติการ |
| Gate P | ก่อน Production | Phase 5 + Restore Test + Human Approval |
