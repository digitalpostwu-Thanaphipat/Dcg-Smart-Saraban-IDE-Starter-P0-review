# โครงสร้างข้อมูลและ Google Sheets

ยึด `docs/00-แผนหลักระยะที่-1.md` และ `docs/data-dictionary.md` เป็นหลัก  
(อัปเดต DCS-P0-001: รายการ 17 ชีต)

## หลักบังคับ

- ใช้แถวที่ 1 เป็นหัวคอลัมน์ภาษาไทยที่ผ่านการรับรอง
- ทุกตารางมีรหัสรายการไม่ซ้ำ, วันเวลาสร้าง, วันเวลาปรับปรุง และรุ่นข้อมูลตามความจำเป็น
- การเรียงคอลัมน์เปลี่ยนได้ แต่ชื่อหัวคอลัมน์ที่บังคับห้ามเปลี่ยน ลบ หรือซ้ำ
- การเขียนข้อมูลต้องทำผ่านชั้นข้อมูลเดียวที่ตรวจ Schema, สิทธิ์, Lock และ Audit
- ห้ามอ่าน/เขียนด้วยลำดับคอลัมน์หรือ `row[index]` — ใช้ชื่อหัวคอลัมน์ตาม Data Dictionary
- Runtime ตรวจ Header Hash กับ Schema Manifest (`docs/schema-manifest-spec.md`)

## คอลัมน์ควบคุมโครงสร้าง

`ชื่อชีต`, `รุ่นโครงสร้าง`, `รายการหัวคอลัมน์ที่บังคับ`, `รหัสตรวจสอบหัวคอลัมน์`, `สถานะโครงสร้าง`, `วันเวลาตรวจสอบล่าสุด`, `ผู้อนุมัติการเปลี่ยนโครงสร้าง`, `เอกสารอ้างอิงการเปลี่ยน`

## คอลัมน์ Audit Log (`บันทึกเหตุการณ์`)

`รหัสเหตุการณ์`, `วันเวลา`, `ผู้กระทำ`, `บทบาทผู้กระทำ`, `ประเภทเหตุการณ์`, `ข้อมูลที่เกี่ยวข้อง`, `รหัสรายการ`, `ค่าก่อนเปลี่ยน`, `ค่าหลังเปลี่ยน`, `ผลการดำเนินการ`, `รหัสอ้างอิง`, `รหัสตรวจสอบเหตุการณ์ก่อนหน้า`

ห้ามเก็บ Secret หรือข้อมูลส่วนบุคคลเกินจำเป็นใน Audit Log
