# ADR-03 — D-03: SLA กลั่นกรองชั้นที่ 1 และชั้นที่ 2

| ฟิลด์ | ค่า |
|--------|-----|
| สถานะ | **Deferred** (ยังไม่ได้รับรับรอง — ห้ามเดาค่า SLA) |
| วันที่บันทึก | 2569-07-16 |
| ผู้ตัดสินที่คาดหวัง | ผู้รับผิดชอบสารบรรณ |
| อ้างอิง | `docs/00-แผนหลักระยะที่-1.md` |

## สิ่งที่ต้องการจากผู้มีอำนาจ

- กำหนด SLA จริง: กลั่นกรองชั้นที่ 1 และชั้นที่ 2 กี่วันทำการ
- ปฏิทินวันหยุด/นโยบายนับวันทำการ (ถ้าระบุ)

## ผลกระทบจนกว่าจะมีคำตัดสิน

- **บล็อก:** การตั้งค่า SLA จริงในระบบและการแจ้งเตือนเกิน SLA ที่อิงค่า production
- **ไม่บล็อก:** งานเอกสาร, scaffold จำลอง, Workflow โครงสร้าง, ช่องค่าตั้งค่า SLA ว่าง/ยังไม่บังคับใช้

## ห้าม

- Agent ห้ามใส่จำนวนวันทำการเป็นค่า default ธุรกิจโดยไม่มีผู้รับรอง
