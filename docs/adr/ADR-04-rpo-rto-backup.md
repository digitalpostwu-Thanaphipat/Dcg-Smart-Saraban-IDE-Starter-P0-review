# ADR-04 — D-04: RPO/RTO และระยะเก็บ Backup

| ฟิลด์ | ค่า |
|--------|-----|
| สถานะ | **Deferred** (ยังไม่ได้รับรับรอง — ห้ามเดา RPO/RTO) |
| วันที่บันทึก | 2569-07-16 |
| ผู้ตัดสินที่คาดหวัง | ผู้รับผิดชอบ IT |
| อ้างอิง | `docs/00-แผนหลักระยะที่-1.md`, `docs/backup-restore-contract.md` |

## สิ่งที่ต้องการจากผู้มีอำนาจ

- RPO (ยอมสูญข้อมูลได้สูงสุดกี่ชั่วโมง/วัน)
- RTO (กู้ระบบกลับใช้ได้ภายในกี่ชั่วโมง)
- ระยะเก็บสำรองรายวัน/สัปดาห์/เดือน และผู้รับผิดชอบ

## ผลกระทบจนกว่าจะมีคำตัดสิน

- **บล็อก:** Release Production
- **ไม่บล็อก:** ออกแบบ Backup/Restore Contract, บันทึกรูปแบบ `บันทึกการสำรองและกู้คืนข้อมูล`, งานจำลอง
- โครงรอบสำรองในเอกสาร (วัน/สัปดาห์/เดือน) เป็น**ข้อเสนอปฏิบัติการ** ไม่ใช่ค่า RPO/RTO ที่รับรองแล้ว

## เกณฑ์ที่เกี่ยวข้อง (ไม่แทนที่ D-04)

- ห้าม Production ก่อนผ่าน Restore Test บนพื้นที่ทดสอบ (ตามแผนดำเนินงานและ Contract)
