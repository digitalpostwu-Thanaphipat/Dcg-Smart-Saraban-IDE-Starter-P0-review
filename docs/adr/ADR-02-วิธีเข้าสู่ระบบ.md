## ตัดสินใจ (ข้อเสนอ)

ใช้ Google Workspace Authentication ในระยะที่ 1

## เงื่อนไข

- ฝ่าย IT ยืนยัน Domain และกลุ่มผู้ใช้ก่อนเปิดใช้งานจริง
- ช่วงจำลอง: ใช้ผู้ใช้ทดสอบ/fixture — ห้ามผูกบัญชีจริงจนกว่าได้สิทธิ์ Workspace (Gate S ตาม `docs/10`)

## ผลกระทบ

- Auth layer ออกแบบสำหรับ Google Workspace ก่อน
- รองรับ SSO มหาวิทยาลัยได้ในอนาคตโดยไม่ผูก UI กับรายละเอียด IdP ปัจจุบัน
