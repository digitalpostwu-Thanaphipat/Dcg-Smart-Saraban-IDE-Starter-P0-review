# ADR-06 — D-06: การเชื่อมระบบสารบรรณเดิม

| ฟิลด์ | ค่า |
|--------|-----|
| สถานะ | **เสนอให้รับรอง** (รอผู้มีอำนาจระบุชื่อ/วันรับรองจริง) |
| วันที่บันทึก | 2569-07-16 |
| อ้างอิง | `docs/00-แผนหลักระยะที่-1.md` |

## ตัดสินใจ (ข้อเสนอ)

ยังไม่เชื่อมระบบสารบรรณเดิมในระยะที่ 1

## ผลกระทบ

- ไม่มี Integration กับระบบเดิมในขอบเขตส่งมอบระยะที่ 1
- ออกแบบ API/ชั้นบริการให้พร้อมเชื่อมต่อในอนาคตโดยไม่ hardcode คู่เชื่อม
