## ตัดสินใจ (ข้อเสนอ)

ระยะที่ 1 ใช้ Google Sheets เป็นฐานปฏิบัติงาน โดยออกแบบ Repository/Data Contract เพื่อย้าย PostgreSQL ได้ภายหลัง

## เหตุผล

- ต้นทุนต่ำ ตั้งค่าเร็ว ไม่ต้องรอ Cloud infrastructure
- Repository Pattern ตั้งแต่ต้นเพื่อย้าย PostgreSQL โดยไม่ต้องแก้ Business Logic

## ผลกระทบต่อข้อมูลบุคลากร/หน่วยงาน

- Source of Truth คือโครงการแยก `Dcg ฐานข้อมูลกลางบุคลากรและโครงสร้างองค์กร`
- Saraban เก็บเฉพาะภาพข้อมูลอ้างอิง ณ เวลานั้น สิทธิ์ และหน่วยงานที่เกี่ยวข้อง
- ห้ามสร้างข้อมูลบุคลากรซ้ำใน Saraban

## ผลกระทบต่อสถาปัตยกรรม

- ชั้น `server/data/` แยก Data Source: อ่านบุคลากรจากกลาง (เมื่อได้รับสิทธิ์), เก็บข้อมูลสารบรรณในชีตของโครงการ
- ช่วงจำลอง: แหล่งบุคลากรใช้ Mock Contract เท่านั้น

## ผลเมื่อรับรอง / ยังไม่รับรอง

- รับรองแล้ว: อนุญาตออกแบบและพัฒนาตาม Sheets + Repository
- ยังไม่รับรอง: งานเอกสารและจำลองตามข้อเสนอชั่วคราวนี้ทำได้; ห้าม deploy ข้อมูลจริง
