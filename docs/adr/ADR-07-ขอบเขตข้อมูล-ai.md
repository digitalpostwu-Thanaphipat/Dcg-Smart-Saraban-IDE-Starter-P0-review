# ADR-07 — D-07: ขอบเขตข้อมูลที่ส่งให้ AI

| วันที่บันทึก | 2569-07-16 |
| อ้างอิง | `docs/00-แผนหลักระยะที่-1.md`, `AGENTS.md` |

## ตัดสินใจ (ข้อเสนอ)

ปิด AI สำหรับข้อมูลจริงใน Production จนกว่าจะมีนโยบายข้อมูลและการอนุมัติผู้ให้บริการ

## ผลกระทบ

- ฟีเจอร์ AI (เช่น ช่วยร่าง) ทำงานเฉพาะบนข้อมูลตัวอย่าง/จำลองในระยะที่ 1
- ห้ามส่งข้อมูลจริงหรือข้อมูลส่วนบุคคลเกินจำเป็นผ่าน AI API
- AI เป็นผู้ช่วยเสนอเท่านั้น — ห้ามอนุมัติ ออกเลข ลงนาม หรือแก้เนื้อหาโดยไม่มีผู้ใช้ยืนยัน (`AGENTS.md`)
