# ข้อกำหนดระบบ

## บทบาท

| บทบาท | สิทธิ์หลัก |
|---|---|
| ผู้ใช้งานทั่วไป | ร่าง ส่ง แก้ตามข้อสังเกต ดูเอกสารของตน และรับ PDF ควบคุม |
| ผู้กลั่นกรองชั้นที่ 1 | รับคิว ตรวจรูปแบบ ภาษา องค์ประกอบ ส่งต่อหรือส่งกลับ |
| ผู้กลั่นกรองชั้นที่ 2 | ตรวจขั้นสุดท้าย อนุมัติ และออกเลขหนังสือ |
| ผู้ดูแลระบบ | จัดการผู้ใช้ สิทธิ์ แม่แบบ ค่าตั้งค่า รายงาน และการติดตามระบบ |
| ผู้ตรวจสอบ | อ่านรายงานและ Audit Log ตามสิทธิ์ โดยแก้ข้อมูลไม่ได้ |

## สถานะเอกสาร

`ร่าง`, `รอส่ง`, `รอกลั่นกรองชั้นที่ 1`, `ส่งกลับแก้ไข`, `รอกลั่นกรองชั้นที่ 2`, `ออกเลขแล้ว`, `ยกเลิก`, `ฉบับแทนที่`, `แนบฉบับลงนามแล้ว`

ทุกการเปลี่ยนสถานะต้องตรวจสิทธิ์ ตรวจ transition ที่อนุญาต และเขียน Audit Log

## ตัวชี้วัดการนับ

- จำนวนเอกสาร: นับ `รหัสเอกสาร` แบบไม่ซ้ำ
- ภาระงานกลั่นกรอง: นับเหตุการณ์รับตรวจ ส่งกลับ ส่งต่อ และอนุมัติทุกครั้ง
- จำนวนออกเลข: นับเหตุการณ์ออกเลขสำเร็จเท่านั้น
- เอกสารยกเลิกและฉบับแทนที่ต้องแสดงแยก ไม่ปนกับจำนวนออกเลขสำเร็จ
