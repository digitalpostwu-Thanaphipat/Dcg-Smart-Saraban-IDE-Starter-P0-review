# Dcg ฐานข้อมูลกลางบุคลากรและโครงสร้างองค์กร

เป็น**โครงการแยก**จาก Dcg Smart Saraban ทำหน้าที่เป็นฐานข้อมูลอ้างอิงกลางที่รับข้อมูลจาก HR ไม่ใช่ระบบ HR หลัก

> เอกสารนี้บรรยายขอบเขตโครงการฐานกลางตามที่ทีมสารบรรณต้องรู้เพื่อเชื่อมต่อ  
> **DCS-P0-001 ไม่เปลี่ยนขอบเขตหรือรายการชีตบังคับของโครงการฐานกลางเอง**

## ชีตหลักของโครงการฐานกลาง (ตามที่ระบุเดิม)

`ข้อมูลบุคลากร`, `หน่วยงาน`, `ตำแหน่ง`, `การสังกัดและการแต่งตั้ง`, `สายบังคับบัญชา`, `แหล่งข้อมูลและรอบนำเข้า`, `การควบคุมโครงสร้าง`, `บันทึกเหตุการณ์`, `บันทึกการสำรองข้อมูล`

## หลักบังคับ (ขอบเขตฐานกลาง — คงเดิม)

- ใช้รหัสบุคลากร รหัสหน่วยงาน และรหัสตำแหน่งกลางร่วมกันทุกโครงการ
- ย้ายหน่วยงาน/เปลี่ยนตำแหน่งต้องปิดช่วงเดิมและเพิ่มช่วงใหม่ ห้ามแก้ทับประวัติ
- ผู้พ้นสภาพเปลี่ยนสถานะ ห้ามลบ
- สิทธิ์การใช้งานเป็นข้อมูลเฉพาะโครงการปลายทาง ไม่อยู่ในฐานกลาง
- โครงการปลายทางอ่านผ่านชั้นบริการข้อมูลกลาง และเก็บ snapshot ที่จำเป็นสำหรับประวัติ

## ผลกระทบต่อ Dcg Smart Saraban

| หัวข้อ | รายละเอียด |
|--------|------------|
| Source of Truth | บุคลากร/หน่วยงาน/ตำแหน่ง มาจากฐานกลาง — ห้ามสร้างซ้ำใน Saraban |
| ชีตใน Saraban | `ข้อมูลบุคลากร`, `หน่วยงาน` = **ภาพอ้างอิง/นำเข้า** เท่านั้น (`docs/00`, `docs/data-dictionary.md`) |
| สิทธิ์ระบบ | เก็บใน `การกำหนดสิทธิ์` ของ Saraban เท่านั้น |
| ช่วงจำลอง | Mock Contract — ห้ามเชื่อมฐานกลางจริงจนกว่ามีเจ้าของ วิธีเข้าถึง Data Contract และสิทธิ์ที่อนุมัติ (ADR-01) |

## ข้อเสนอ sync ชื่อชีต (ไม่ใช่คำสั่งเปลี่ยนขอบเขตฐานกลาง)

| รายการ | ชื่อในเอกสารฐานกลาง (ปัจจุบัน) | ชื่อใน Saraban ตาม docs/00 | ข้อเสนอ |
|--------|----------------------------------|----------------------------|---------|
| บันทึกสำรอง/กู้คืน | `บันทึกการสำรองข้อมูล` | `บันทึกการสำรองและกู้คืนข้อมูล` | **เสนอ** ให้เจ้าของโครงการฐานกลางพิจารณา align ชื่อและชนิดปฏิบัติการ (สำรอง / ทดสอบกู้คืน / กู้คืนจริง / ล้มเหลว) เมื่อมีรอบปรับปรุงเอกสารฐานกลาง — **ไม่บังคับเปลี่ยนในงาน DCS-P0-001** |
| บุคลากร / หน่วยงาน | ชื่อชีตตรงกัน | ใช้ชื่อเดียวกันแต่ความหมายเป็นภาพใน Saraban | คงชื่อ; แยกความหมายด้วยเอกสารและชั้นข้อมูล |

**ผู้ตัดสินการเปลี่ยนชื่อชีตฐานกลาง:** เจ้าของโครงการฐานข้อมูลกลางบุคลากร — ไม่ใช่ Agent ของ Saraban

## สิ่งที่ห้ามทำจากงานสารบรรณ

- ห้ามลบหรือลดชีต/หลักบังคับของฐานกลางผ่านเอกสารนี้
- ห้ามย้ายสิทธิ์ RBAC ของ Saraban เข้าไปอยู่ในฐานกลาง
- ห้ามถือว่าการ “เสนอ sync ชื่อ” คือการรับรองแล้ว
