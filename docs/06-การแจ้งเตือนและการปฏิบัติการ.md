# การแจ้งเตือนและการปฏิบัติการ

ศูนย์แจ้งเตือนบนหน้าเว็บเป็นช่องทางหลัก มีไอคอนกระดิ่ง จำนวนที่ยังไม่อ่าน รายการล่าสุด หน้ารวม และลิงก์ไปยังงานโดยตรง

เหตุการณ์ขั้นต่ำ: งานใหม่ชั้นที่ 1/2, ส่งกลับแก้ไข, ใกล้หรือเกิน SLA, ออกเลขและ PDF พร้อม, ยกเลิก/แทนที่, Backup ล้มเหลว และโควตาใกล้เต็ม

ตาราง `การแจ้งเตือน` ต้องมี: `รหัสการแจ้งเตือน`, `รหัสผู้รับ`, `ประเภทการแจ้งเตือน`, `ระดับความสำคัญ`, `หัวข้อ`, `ข้อความ`, `รหัสเอกสาร`, `ปลายทางเมื่อกด`, `วันเวลาสร้าง`, `สถานะอ่านแล้ว`, `วันเวลาอ่าน`, `วันเวลาหมดอายุ`

หน้าเว็บดึงเฉพาะจำนวนยังไม่อ่านและรายการใหม่เป็นช่วงเวลา ห้ามดึง Audit หรือเอกสารทั้งหมดทุกครั้ง
