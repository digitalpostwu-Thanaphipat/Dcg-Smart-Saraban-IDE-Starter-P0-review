# ค่าตั้งค่าและแม่แบบ

## หลักการ

ค่าที่เปลี่ยนได้ทางธุรกิจและรูปแบบต้องเป็นข้อมูลตั้งค่า ไม่ Hardcode ใน Front-end หรือ Back-end ค่าตั้งค่าทุกชุดมีรุ่น ผู้เสนอ ผู้อนุมัติ วันเริ่มมีผล เหตุผล และ Audit Log

## ชีตตั้งค่าที่ต้องมี

| ชื่อชีต | ขอบเขต |
|---|---|
| `การตั้งค่าระบบ` | เขตเวลา ปีงบประมาณ สถานะเปิด/ปิดบริการ |
| `การตั้งค่าหน้าจอ` | ฟอนต์ ขนาด สี และข้อความมาตรฐาน |
| `การตั้งค่ารูปแบบเอกสาร` | ฟอนต์ ขนาด ระยะขอบ ระยะบรรทัด ย่อหน้า และตำแหน่งองค์ประกอบ |
| `ประเภทหนังสือและแม่แบบ` | ประเภท รุ่นแม่แบบ กฎ และสถานะรับรอง |
| `การตั้งค่า Workflow` | สถานะ SLA นโยบายคิว และการแจ้งเตือน |
| `การตั้งค่ารายงาน` | นิยามตัวชี้วัดและรอบสรุป |
| `การตั้งค่าการสำรองข้อมูล` | รอบสำรอง ระยะเก็บ และปลายทาง |

## ค่าที่ห้ามเปิดเป็นการตั้งค่า

การแยกผู้กลั่นกรอง 2 ชั้น, การล็อกเอกสารหลังออกเลข, การตรวจสิทธิ์ฝั่ง Backend, การเขียน Audit Log และข้อห้ามหน้าเว็บเข้าถึง Sheets โดยตรง ต้องตรึงในโค้ดและทดสอบ
