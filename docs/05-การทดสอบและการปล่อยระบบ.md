# การทดสอบ Scalability และการปล่อยระบบ

## Test ที่บังคับ

- Unit Test: Business Rules, สิทธิ์, สถานะ, เลขหนังสือ, Schema และรายงาน
- Playwright E2E: ร่าง → กลั่นกรอง 1/2 → ออกเลข → PDF ควบคุม → อัปโหลดฉบับลงนาม
- Load/Concurrency: เปิดงาน ค้นหา บันทึก ส่งคิว และออกเลขพร้อมกัน
- Soak Test: ใช้ระบบต่อเนื่องพร้อมรายงานและ Backup
- Restore Test: กู้ Sheets, ไฟล์, Audit และตรวจความครบถ้วน

## เกณฑ์เริ่มต้นสำหรับ UAT

- ทดสอบผู้ใช้พร้อมกัน 50, 100 และ 200 คน
- ทดสอบคำขอออกเลขพร้อมกันอย่างน้อย 20 คำขอ โดยห้ามเลขซ้ำหรือข้อมูลหาย
- P95 เปิด/ค้นหารายการทั่วไปไม่เกิน 2 วินาที
- P95 บันทึกร่างหรือส่งกลั่นกรองไม่เกิน 3 วินาที
- P95 รายงานจากข้อมูลสรุปไม่เกิน 3 วินาที

ค่าทั้งหมดต้องยืนยันอีกครั้งจากปริมาณผู้ใช้งานสูงสุดจริงและโควตาของบัญชี Google Workspace ที่ใช้จริง

## Release

ทุก Release ต้องผ่าน lint, type check, Unit Test, Playwright, Security/Secret Scan, Code Review, Staging และ Human Approval ก่อน Production
