# ตรวจหนังสือราชการก่อนกลั่นกรอง

1. อ่านประเภทหนังสือ รุ่นแม่แบบ กฎรูปแบบ และ Acceptance Criteria ที่ผ่านการรับรองก่อนตรวจ
2. ตรวจข้อมูลบังคับตามประเภทหนังสือ เช่น ส่วนราชการ ที่ วันที่ เรื่อง คำขึ้นต้น/ลงท้าย อ้างถึง สิ่งที่ส่งมาด้วย ข้อความ และผู้ลงนามตามที่แม่แบบกำหนด
3. ตรวจรูปแบบ A4 ฟอนต์ ระยะขอบ ระยะบรรทัด การย่อหน้า และองค์ประกอบตามรุ่นค่าตั้งค่าของเอกสาร
4. แยกผลตรวจเป็น `ผ่าน`, `ต้องแก้ไข`, `ข้อมูลไม่ครบ` พร้อมตำแหน่ง เหตุผล และคำแนะนำภาษาไทยที่ผู้ใช้แก้ได้จริง
5. ห้าม Skill อนุมัติ ออกเลข ลงนาม หรือแก้เนื้อหาแทนผู้ใช้; ให้เสนอและรอการยืนยันเท่านั้น
6. เมื่อส่งกลับแก้ไข ให้บันทึกข้อสังเกตเป็นรายการตรวจสอบที่อ้างอิงรุ่นเนื้อหา ไม่ทำลายประวัติเดิม

เสร็จเมื่อ: มี checklist ตามประเภทหนังสือ, แสดงผลตรวจตามตำแหน่ง, เก็บรุ่นแม่แบบ/เนื้อหา และมี Unit/E2E Test สำหรับการป้องกันส่งเอกสารที่ข้อมูลบังคับไม่ครบ
