# Google Sheets Data Contract

1. อ่าน `docs/02-ข้อมูลและ-Google-Sheets.md` และ Data Dictionary ที่เกี่ยวข้องก่อนแก้ไข
2. ระบุชื่อชีต หัวคอลัมน์บังคับ ชนิดข้อมูล รหัสหลัก และผลกระทบต่อรายงาน/Backup
3. สร้าง mapping จากชื่อหัวคอลัมน์ภาษาไทย ห้ามอ้างอิงลำดับคอลัมน์
4. ตรวจหัวคอลัมน์หาย ซ้ำ เปลี่ยนชื่อ และรุ่นโครงสร้างก่อนอ่านหรือเขียนข้อมูล
5. อ่าน/เขียนเป็นชุด และบันทึก Audit Log สำหรับการเปลี่ยนสำคัญ
6. ถ้า Schema ไม่ตรง ให้หยุดงาน บันทึกข้อผิดพลาด และไม่เขียนข้อมูลบางส่วน

เสร็จเมื่อ: มีการทดสอบกรณีสลับคอลัมน์ หัวคอลัมน์หาย/ซ้ำ ข้อมูลไม่ผ่าน และการเขียน Audit Log
