# คุณภาพ UI ภาษาไทย

1. อ่าน `DESIGN.md`, `AGENTS.md` และ Workflow ที่เกี่ยวข้องก่อนออกแบบ
2. ใช้คำไทยมาตรฐานสำหรับป้ายกำกับ ปุ่ม สถานะ Error Help และ Notification ห้ามปล่อยข้อความดิบจาก Service/Library
3. ออกแบบ Loading, Empty, Error, No-permission, Validation, Success และ Confirmation State ทุกหน้าจอ
4. ฟอร์มร่างต้องแสดงข้อมูลบังคับ ข้อผิดพลาดตามตำแหน่ง และ A4 Preview แบบเรียลไทม์โดยไม่ล้างข้อมูลผู้ใช้
5. ตรวจ Desktop เป็นหลัก และ Mobile สำหรับติดตาม/อ่าน/ตรวจงาน พร้อมคีย์บอร์ด ป้ายกำกับฟอร์ม และการไม่พึ่งสีเพียงอย่างเดียว
6. อ่านสี ฟอนต์ ขนาด ระยะห่าง และข้อความมาตรฐานจาก Design Token/ค่าตั้งค่าที่รับรอง ห้าม Hardcode
7. ตรวจสิทธิ์และกฎธุรกิจผ่าน Backend เสมอ UI มีหน้าที่นำเสนอ ไม่ใช่จุดตัดสินสิทธิ์

เสร็จเมื่อ: UI เป็นภาษาไทย 100%, ครบทุกสถานะ, ผ่าน Responsive/Accessibility ขั้นพื้นฐาน และมี Playwright E2E สำหรับเส้นทางสำคัญที่แก้ไข
