# งานพร้อมกันและ Audit

1. ระบุทรัพยากรส่วนกลางและ Business Rule ที่ต้องปกป้อง
2. ตรวจสิทธิ์ฝั่ง Backend ก่อนดำเนินการ
3. ใช้ Lock สำหรับการออกเลขหรือการแก้ข้อมูลร่วมกัน และกำหนด timeout/ข้อความผิดพลาดภาษาไทย
4. ใช้รหัสคำขอเพื่อให้คำสั่งซ้ำไม่สร้างเลขหรือ Audit ซ้ำ
5. บันทึก Audit แบบเพิ่มอย่างเดียว พร้อมผู้กระทำ เวลา ก่อน/หลัง ผลลัพธ์ และรหัสอ้างอิง
6. ปล่อย Lock ในทุกกรณีและทดสอบคำขอพร้อมกัน

เสร็จเมื่อ: มี Unit Test และ E2E/Concurrency Test ที่พิสูจน์ว่าไม่มีเลขซ้ำ ข้อมูลหาย สถานะข้ามขั้น หรือ Audit ขาดช่วง
